# 当前阅读章节听书入口修复

Android 0.8.2（versionCode 13），安装包 `dist/shanye-0.8.2-debug.apk`，校验见 `apk-sha256.txt`。

## 行为

- 阅读页传入的当前章节按书籍/章节 ID 匹配，不再被其他章节的播放会话覆盖，也不会自动退到本书第一个有声章节。
- 使用本章正在播放的版本或已选择的音色版本。切换章节后点击播放，从当前阅读位置对应的语音开始；同章已有会话保持当前进度。
- 本章缺少音频时保留书名和章节标题，显示「本章暂无听书内容」及「去合成本章」，合成页预选对应书籍与真实章号。
- 进入其他章节的播放器时暂停之前章节的播放，保留其进度。播放器中的目录、上一章/下一章和音色切换仍可显式选择其他内容。
- 书房和系统媒体通知入口没有指定章节，继续使用已有播放会话。
