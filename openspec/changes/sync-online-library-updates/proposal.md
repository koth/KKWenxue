## Why

当前在线书库导入是一次性把网站正文下载到本地；网站每天更新后，本地书架仍停留在旧章节，用户只能重新导入整本书，且可能丢失阅读进度、重复下载大量旧正文，或者把旧版本音频与新正文错误关联。需要建立稳定的书籍身份、正文版本和增量同步机制，让本地书架可以安全发现并获取网站新增章节。

## What Changes

- 为在线书籍建立稳定的远程书籍绑定信息，保存来源、远程 `bookId`、最后同步版本、最新章节标识和同步时间。
- 目录服务提供轻量级版本检查接口；App 每次启动或恢复到前台时检查书架上的在线书籍，检查阶段只获取元数据。
- 支持按书籍生成更新计划，明确远程新增章节、远程变更/删除、需要重新获取的范围和预计大小。
- 服务端继续负责从书源下载 TXT、分章、校验和打包；更新包只包含新增/变更章节及 manifest，不允许 App 直连书源。
- 默认自动下载并应用纯新增章节的更新，不要求用户逐本确认；用户可以暂停自动更新、取消等待中的任务、重试失败任务。
- App 通过 relay 中转下载更新包，校验书籍身份、前置版本、章节顺序、章节 ID、内容哈希和包哈希后，以原子事务合并到本地书库。
- 更新完成后保留原有章节 ID 和阅读锚点；当前阅读章节未被替换时，章节内 UTF-16 offset 不变；章节内容发生变化时提供明确的锚点迁移策略，不静默跳到其他位置。
- 保留本地书架自定义信息、书签、评论、阅读/听书进度和已导入音频；音频按正文 revision 关联，旧音频不可冒充新正文音频。
- 支持启动时多书分批检查、并发限制、失败重试、过期任务重建和网络中断恢复；自动更新不得改变当前阅读页面或自动播放音频。
- 更新失败时不得覆盖现有可读版本；成功更新后提供更新摘要，并允许从本地备份回滚到上一个正文版本。

## Capabilities

### New Capabilities

- `online-library-sync`: 在线书籍版本检查、增量更新计划、服务端正文更新包、relay 中转、客户端校验合并、失败恢复和回滚。

### Modified Capabilities

无。现有阅读器和听书能力的兼容要求在本变更的 `online-library-sync` 中以交叉约束描述；本变更不改变现有 TTS 合成协议或听书包格式。

## Impact

- **Android App**：`CatalogClient`、在线书架/书籍详情、`LocalBookRepository`、本地书库 schema、`ReaderStore` 版本/进度映射、更新状态 UI 和测试。
- **目录服务**：新增书籍版本检查、更新计划和更新包 API；保留现有正文抓取任务，通过 relay 传输更新包。
- **正文 worker**：保存内容寻址的章节快照，比较远程章节列表，生成增量包，并保证失败时不发布半成品。
- **Relay**：复用正文任务与中转能力，增加更新包的任务去重、过期和状态语义。
- **本地存储**：增加远程绑定、正文 revision、章节内容哈希、同步状态和可回滚版本；旧的本地导入书籍必须可继续阅读。
- **网络与权限**：沿用目录服务的 HTTP/HTTPS 访问和服务器中转；App 不获得书源访问凭据，也不直接请求书源。
