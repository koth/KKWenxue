# 山页 · 精品小说阅读 Android 原型

暖纸色、原生中文排版、随时离线读。Kotlin + Jetpack Compose 构建界面，Android StaticLayout 实际测量并绘制正文。最低 Android 8.0。

## 运行

用 Android Studio 打开本目录，或安装 JDK 17+、Android SDK 35 后运行：

```sh
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.kkwenxue.shanye/.MainActivity
```

如果没有配置 Android SDK 环境变量，在未提交的 `local.properties` 中设置 `sdk.dir`。

## 体验

- 书房：继续阅读、精选书籍、类型筛选。
- 书架：内置示例书和本地 SQLite 书库，支持书名、作者、类型搜索；点“导入”可选择 TXT / EPUB，自动识别章节并保存到本机数据库。
- 阅读：纸页翻动（折页、纸背透字、边缘阴影）与整页平移两种动画，也可关闭动画。支持跟手拖动、松手回弹、速度判定、点击翻页及跨章节连续动画。点击中央开关菜单。
- 文字：中央工具栏提供规则式简/繁切换，自动按书籍初始文本判断当前字形；切换只改变显示层，UTF-16 原文定位、评论、书签和后续 TTS 锚点保持一致，并按书籍记住选择。
- 菜单：返回、添加/取消书签、上一页/下一页、目录、夜读、排版与书签列表。
- 听书：主页与阅读菜单提供入口，可导入工作台的听书 ZIP 包，目录标记「可听」。全屏播放器展示书封、章节和当前句子，支持 0.8×、0.9×、1×、1.1×、1.2× 倍速（保留音高并记住选择）、15/30/45/60 分钟或自定义 1–360 分钟定时、本章结束、拖动进度、前后 15 秒、上一/下一章及已导入音色版本切换；听书目录自动定位当前章节，播完自动续播紧邻下一章，优先保持相同音色；缺章提示合成或导入，「本章结束」定时会停止续播。完整音频、版本和播放进度存本机，支持离线播放、后台/锁屏控制、逐句高亮与原文定位。其他应用开始播放音频时，小说不会被自动暂停，会自动降低音量以便两路声音共存；手动翻页后停止跟随，点「定位原文」可重新开启。阅读页听书浮条右侧的关闭按钮会停止播放、取消跟踪并隐藏浮条，清除定时和媒体通知，保留当前阅读页与听书进度。
- 评论：长按正文中的一句，按 `。！？!?…` 分句，逐行贴合文字高亮，跳过换行、段间空白和首行缩进。选择“评论”写下想法；评论以作品、章节和句子 UTF-16 范围为锚点，换字号和主题后仍能找到原句。
- 排版：纸张/夜读/青苔主题、16–28 字号、宋体/黑体、两种行间距，翻页效果偏好自动保存。系统关闭动画时尊重系统设置。
- 我的：离线藏书数、累计向前翻页数、书签列表和评论列表；点击书签直接返回原文。
- 阅读进度、设置、书签和导入书籍均保存在本机 SQLite；换字体、字号后会重新排版并定位原文。

书籍、阅读进度和听书音频保存在本机，未接入账号或阅读进度云同步。听书支持连接任务服务器，只在显式派发时上传所选章节。示例故事为本项目创作的演示文本。字体为 Noto Serif SC，按 SIL Open Font License 1.1 分发，许可证位于 `licenses/NotoSerifSC-OFL.txt`。

## 验证

```sh
./gradlew :app:connectedDebugAndroidTest :app:lintDebug
```

仪器测试覆盖 SQLite 书库种子、规则式简繁转换、全部内置样章的分页完整性、页面高度、位置恢复、Unicode 边界、设置/书签/评论持久化、中文句子分割与长按选择、高亮排除段间空白/缩进/行间距与跨页裁剪，以及翻页中间帧、短拖回弹、系统取消、连续点击防跳页、跨章节往返、平移模式和动画期间切换外观。听书测试另覆盖 UTF-16 对齐、音频/清单哈希、原文版本校验、重复导入、版本及进度持久化、损坏包/试听拒绝与整包失败回滚，以及实际倍速、暂停时调整倍速、锁屏一分钟定时暂停、本章结束、后台/锁屏自动续播、缺章停止及连续播放时的界面同步；真实 984 章验收需显式提供 `audioBundle`，不把小说音频打进 APK。

## 本地有声书合成

本地 Web 工作台与服务器合成服务已实现，见 [操作文档](server/README.md)、[OpenSpec 设计](openspec/changes/add-tts-synthesis-workbench/design.md) 与 [实施任务](openspec/changes/add-tts-synthesis-workbench/tasks.md)。本地启动：

```sh
cd web && npm ci && npm run build
cd ..
python3 -m local.launcher --open
```

工作台默认读取 `app/src/main/assets/shanye.db` 中《噩夢使徒》的 1,281 章；可用 `--library` 指定其他阅读器数据库。目录、检索和原文均在本地完成；提交时只发送选中章节到 GPU 服务器。正式合成使用 Audio8 0.6B C++ CUDA 引擎，默认 `cwns.mp3` 参考音色、1.0 倍速和 180ms 额外句间停顿。支持 M4A 等参考音频克隆、试听、持久任务、暂停/继续、失败重试、同步播放、M4A/JSON/ZIP 下载。Web 和 App 的新任务均使用参考音色；旧任务及历史音频保留可播放。

Android 0.9.4 可在「听书 → 合成与导入」中直接选择本地书籍、章号范围、参考音色与 0.8×–1.2×成品语速，派发到公网任务服务器；默认使用 cwns 音色和 Audio8。退出 App 后服务器继续执行。「服务器任务」展示进度与完成结果，点「下载并导入」后优先局域网直连，连接失败才申请中转上传，导入后可离线播放。支持分页、任务 ID 查找、派发状态核对、播放器五档倍速和按语音段进度跟踪原文自动翻页。服务器地址和中转凭据在「服务器」中填写或导入连接配置，凭据使用 Android Keystore 加密且不参与备份；手机不持有 GPU 服务的管理凭据。每批 1–100 章，完整说明见 [App 云端合成](docs/android-cloud-synthesis.md)。

从阅读页点「听书」会选择当前章节，优先采用本章正在使用或已选择的音色版本；切换章节时按阅读页位置定位，不会跳回其他章节的旧会话。本章没有音频时显示「本章暂无听书内容」，「去合成本章」预选当前书和章号。书房或系统媒体通知的听书入口继续打开现有播放会话。

原有「导入听书包」入口继续支持工作台手动下载的 ZIP。书籍 ID、章节 ID、原文哈希、修订、UTF-16 定位、清单/音频哈希及容器时长均须匹配；每包最多 1,000 个版本、4 GB。

`tts/` 中原有本地 MLX 与 CUDA CLI 仅作为历史工具保留，正式服务不调用。服务未自动恢复清理前书库或批量任务。

外网异步接单使用独立的 [Rust 通用任务中转服务](relay/README.md)：按类型投递任务，worker 轮询领取、续租，完成时先发布结果元数据和直连地址。GPU 侧的 [TTS 适配器](server/README.md#外网任务中转) 复用现有合成队列，ZIP 留在 GPU 主机，客户端连不上局域网时才申请上传中转。中转包默认保留 24 小时；其他任务类型可接入各自的 worker。
